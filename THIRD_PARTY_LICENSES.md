### Vivliostyle (AGPL-3.0)

(`@vivliostyle/core`), licensed under the GNU Affero General Public License v3.0.
GPLv3 §13 permits combining it with Saga-Scribe; Vivliostyle itself stays under the
AGPL. The complete corresponding source of every Saga-Scribe release, including
the Vivliostyle version it ships, is available from this repository
(https://github.com/motheatensoul/saga-scribe), and Vivliostyle's own source from
its repository above.

### libxml2 (MIT)

XML parsing and schema validation use [libxml2](https://gitlab.gnome.org/GNOME/libxml2)
through the `libxml` crate. Linux and macOS builds link the system library; the
Windows build links it statically (from vcpkg), so it ships inside the binary.
Licence: MIT.

- **Files:** `static/entities/menota.json`, `static/normalizer/entity-base-letters.json`

  norrøne prosasprog), University of Copenhagen / Arnamagnæan Commission
- **Licence:** to be confirmed (the ONP site states a Creative Commons licence)
- **Source:** https://onp.ku.dk/
